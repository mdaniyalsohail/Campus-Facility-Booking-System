# Campus Hub — Next-Gen Campus Facility Booking System

A unified platform for student life management: library rooms, sports courts, cafeteria pre-orders, and career counseling appointments.

🔗 **Live demo:** https://cfbs.netlify.app/
**Demo login:** `2024001` / `password`

## Modules
- **Library Room Booking** — group study rooms (4–6 seats), 9 AM–6 PM slots, unique booking IDs
- **Sports Court Booking** — basketball & badminton, morning/evening slots
- **Cafeteria Pre-Ordering** — menu with pricing, order history, 20–25 min pickup
- **Career Counseling** — appointment booking with counselor selection
- **My Bookings** — manage all bookings/appointments in one place; library and court bookings are cancellable (restores slot availability), cafeteria orders are not

## Tech Stack
JavaScript, HTML5, CSS3 — dashboard-based navigation with local storage for persistence

## Design
Dark mode UI with neon-blue highlights, card-based layout, real-time slot availability
